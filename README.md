# Hrutuja Satpute — Portfolio Website

Personal portfolio website built with vanilla HTML/CSS/JS, hosted on GitHub Pages.

🔗 **Live Site**: https://hrutuja09.github.io

## Setup

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Set Source to **Deploy from branch → main → / (root)**
4. Save — your site will be live at `https://<your-username>.github.io`

## Customization

All content is in `index.html`. To update:
- **Projects**: Find the `<!-- PROJECTS -->` section
- **Experience**: Find the `<!-- EXPERIENCE -->` section
- **Skills**: Find the `<!-- SKILLS -->` section
- **Contact links**: Find the `<!-- CONTACT -->` section

## Adding your Resume PDF

Place your resume PDF in this folder named `Resume_Backend_Hrutuja.pdf`.
The "Download Resume" button is already linked to it.

## Structure

```
portfolio/
├── index.html              # Main portfolio page
├── Resume_Backend_Hrutuja.pdf  # Your resume (add this)
└── README.md               # This file
```
