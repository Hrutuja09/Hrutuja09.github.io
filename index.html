Incident Co-pilot
LLM Incident Triage Service · June 2026

A Python incident-triage service integrating the Anthropic API that diagnoses infrastructure outages from a time window alone — reaching 0.85 confidence on a DB-down fault with no symptom hints. Built as a three-stage pipeline (Collector → Context Builder → Analyzer) with typed Pydantic contracts, a configurable lookback buffer to capture pre-symptom causes, and graceful degradation when dependencies are unreachable. Automates end-to-end fault injection and diagnosis into a single command: baseline traffic generation, Postgres outage simulation with programmatic timestamp capture, and an LLM-generated RCA report with cited evidence.
